# B8 negative corpus sources

Generated by `scripts/generate_negative_corpus.py`. Each program is
unit conversion, clamp, lerp, date, BMI, PID, flags, IPv4, mortgage, or
log-level code — **not** a labeled algorithm-recovery target.

These exist so specification-extraction detectors can be scored for
**false positives**. Ground-truth sidecars are `{"labels":[]}`. They are
not product samples and are not shipped in v2.0.22 installers.

Rebuild binaries with:

```bash
bash scripts/build_negative_corpus.sh
```

Run the false-positive extract with:

```bash
bash scripts/ci/run_b8_negative_corpus.sh
```

Loop-containing negatives live in `../negative_loops/` and are built with
`scripts/build_negative_loop_corpus.sh`. Results: `results/b8-negative-*.json`
and `results/b8-loop-negatives.md`.
