without one is `unpublished` or `withdrawn`. Generate marketing copy from
this table; do not treat README, the whitepaper, or CHANGELOG as evidence.

artefact · `withdrawn` — published then retracted · `opt-in` — off unless
the named flag is set · `asserted` — narrative only (not demonstrated).

`manual` — read the named artefact; `asserted` — no machine check.

## How to use

1. Do not republish C-ALGO-F1, C-CUDA-PIPE, C-NEURAL-DIFF, C-CXX-EMIT,
   C-FAST24, or C-QWEN3-GPU. Do not claim C-DOCKER-HUB. C-LICENCE is
   **asserted**. C-APPIMAGE is **opt-in**, not the default Linux package.
2. C-DB-COMPARE artefacts exist. When they disagree with CC-01, cite both
   files rather than silently picking the better number.
3. Opt-in rows are capabilities, not default-on product features.
4. Whitepaper and README must not outrun this register.
